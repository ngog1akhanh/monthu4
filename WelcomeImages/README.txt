Put your welcome slideshow images in this folder.

Supported formats: .jpg, .jpeg, .png, .bmp, .gif

Files placed here will be loaded at runtime from the application's folder (AppContext.BaseDirectory/WelcomeImages).

Tips:
- Add a few landscape images sized around 1280x720 or similar for best fit.
- Restart the app after adding images if the app is already running.
- If you want to change slide interval, edit Forms/FormWelcome.cs (slideTimer.Interval in milliseconds).
